## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| copy constants to users | Notices, banners and refusals must not leak signing or contract detail or mislead about permissions |
| effect classification to enforcement | A wrong class either blocks recovery or leaves a write path open |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-14-06-01 | Information disclosure | notice and refusal copy | medium | mitigate | Closed copy sets; unknown keys render generic text; forbidden-words guard over all exports; emails carry no deployment ID, key or contract detail |
| T-14-06-02 | Elevation of privilege | a write permission classified continuity | high | mitigate | Exact-set tests for all three classes; capability-list test requires every write permission in a blocked item; effects exhaustive over the closed catalogue |
| T-14-06-03 | Denial of service | licence.activate classified blockable | high | mitigate | licence.activate is continuity and asserted present in a works item; plan 14-21 proves activation succeeds while restricted |
| T-14-06-04 | Spoofing | refusal message confused with a permission denial | low | mitigate | isLicenceRefusalMessage compares a distinct constant so the UI can render the refusal differently from a role denial |
</threat_model>
