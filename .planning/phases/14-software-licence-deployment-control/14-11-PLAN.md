<objective>
Inject the restricted-state guard into the `withPermission` choke point and bind it to the database-backed licence service.

Purpose: D-09 locks enforcement inside `withPermission`, default-blocking mutations with an explicit continuity allowlist, so new resources inherit enforcement automatically while an unauthorized caller learns nothing about licence state. Tracer: a wrapped write is refused in a restricted state through the real database path with an audit row.

Output: guard changes to `with-permission.ts`, the live binding in `index.ts`, `refusal.ts`, the shared test harness option, and unit and integration tests.

Interface contract for later plans (do not rename):
- `LicenceGuardDep = { check(input: { permission: Permission; actorId: string }): Promise<{ allowed: true } | { allowed: false }> }`; `WithPermissionDeps.licence?: LicenceGuardDep`.
- `withPermission(permission, resolveScope, options?: { licence?: LicenceEffect; reason?: string })`.
- `LicenceRestrictedError extends AuthorizationError`, `name` "LicenceRestrictedError", `message` LICENCE_REFUSAL_MESSAGE.
- `refusalMessage(error: unknown, deniedMessage: string): string` returns LICENCE_REFUSAL_MESSAGE for a LicenceRestrictedError and deniedMessage otherwise; `isLicenceRestricted(error): error is LicenceRestrictedError`; both exported from `@/server/permissions`.
- `createTestWithPermission(grants, { userId?, licence? })` in `tests/support/harness.ts` forwards `licence`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-14-11-01 | Information disclosure | guard before authorization becomes a state oracle | high | mitigate | Guard placed strictly after hasPermission; parity tests (unit and real database) prove identical errors and zero guard calls |
| T-14-11-02 | Elevation of privilege | write path bypasses the guard by mislabeled effect | high | mitigate | Effects default to write for any unclassified string; per-call overrides require a reason string; plan 14-17 snapshot and registry tests lock every override |
| T-14-11-03 | Denial of service | recovery blocked in restricted state | high | mitigate | licence.activate, exports and sign-in are continuity or outside withPermission; Test 5 proves licence.activate and others run while restricted; plan 14-21 proves recovery end to end |
| T-14-11-04 | Tampering | TOCTOU between check and handler | medium | mitigate | Check runs in the same request immediately before the handler; restriction is monotonic in time; residual window is milliseconds |
| T-14-11-05 | Information disclosure | refusal message leaks state or contract detail | medium | mitigate | Fixed LICENCE_REFUSAL_MESSAGE; no permission, state or reason in the message; tests assert the message equals the constant |
| T-14-11-06 | Repudiation | enforcement not recorded | medium | mitigate | licence.restriction_enforced audit row written by the guard dependency with operation and state (coalesced per actor per minute); integration test asserts the row |
