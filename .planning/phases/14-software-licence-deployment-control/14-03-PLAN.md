## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-03-01 | Tampering | LicenceState / LicenceRecord rows edited directly | medium | mitigate | The raw signed text is stored and re-verified by plan 14-09 on every guarded write, so an edited date or swapped raw text fails the signature; CHECK constraints bound state values; accepted residual: an operator with raw SQL access can reset the row (PRD 18.1: technical checks are not a lock) |
| T-14-03-02 | Tampering | destructive migration | high | mitigate | Additive-only migration; test asserts no DROP statement; db push never receives the data-loss flag; push task stops on any destructive proposal |
| T-14-03-03 | Denial of service | second singleton row | low | mitigate | CHECK constraints pin the singleton ids; test inserts a second row and expects rejection |
| T-14-03-04 | Elevation of privilege | applying schema to a shared database | high | mitigate | Task 2 precondition asserts the database host is local before any command runs |
| T-14-03-05 | Information disclosure | licence raw text in the database | low | accept | The raw licence is signed public data with no secret (D-14); the diagnostic report never returns it |
</threat_model>
