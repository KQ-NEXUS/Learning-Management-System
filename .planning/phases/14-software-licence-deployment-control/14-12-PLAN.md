<objective>
Add explicit restricted-state guards to the learner entry points that bypass `withPermission`: new checkout sessions and new registration, with neutral learner copy.

Purpose: D-08 blocks new checkout sessions while payments already initiated may still complete (plan 14-13), and D-09 requires every non-`withPermission` write path to carry a guard or a documented exemption. Tracer: a blocked `startCheckout` ends in a redirect with the neutral notice.

Output: guard changes in `checkout-service.ts` and `registration-service.ts`, learner action and page mappings, the `unavailable` notice and tests.

Interface contract: the injected dependency type is `licence?: { assertWriteAllowed(input: { operation: string; actorId?: string | null }): Promise<void> }` (plan 14-09 `licenceService` satisfies it); the error is `LicenceWriteBlockedError` from `src/server/licence/errors.ts` (plan 14-02); `RegistrationResult` gains `{ ok: false; reason: "UNAVAILABLE" }`.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-14-12-01 | Elevation of privilege | new checkout or registration continues in restricted state | high | mitigate | Guard called first in startCheckout, both initiate functions and registerLearner; unit tests prove no transaction or provider call; plan 14-17 registry test requires the guard in these files |
| T-14-12-02 | Information disclosure | learner learns the licence state | medium | mitigate | Neutral copy constant, no licence words; test asserts absence; refusal rendered through existing notice style |
| T-14-12-03 | Information disclosure | registration refusal becomes an email enumeration oracle | medium | mitigate | Guard runs after validation and before any store call, identical result for any email; test compares existing and new email |
| T-14-12-04 | Denial of service | payment initiated before restriction cannot complete | high | mitigate | Only session creation is blocked here; settlement of already-initiated payments is plan 14-13 and webhooks remain outside the guard |
