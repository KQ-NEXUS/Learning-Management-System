## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Netlify scheduler to function | Unauthenticated scheduler invocation runs privileged evaluation |
| startup hook to boot | A slow or failing check could prevent the server from becoming ready |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-14-16-01 | Denial of service | startup check blocks or crashes boot | high | mitigate | 3-second race, every error caught, register wrapped in try and catch, NEXT_RUNTIME guard; tests for timeout and rejection |
| T-14-16-02 | Elevation of privilege | request-only API leaks into the scheduled runtime | medium | mitigate | Boundary tests for the check-licence closure, webhook closures and licence services; function rejects a Prisma import |
| T-14-16-03 | Information disclosure | logs expose licence detail | low | mitigate | Logs carry state code and counts only; test asserts client name and emails are absent |
| T-14-16-04 | Denial of service | notice or audit flooding from repeated runs | medium | mitigate | Idempotent evaluation (writes only on change) and deterministic notice ids; task skips emission when no keys |
| T-14-16-05 | Repudiation | scheduler absent on the chosen host | medium | accept | Documented hosting note: restriction does not depend on the scheduler, alerts do; operator guidance in the deployment doc (OQ5 adopted default) |
</threat_model>
