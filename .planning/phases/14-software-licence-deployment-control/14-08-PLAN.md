<objective>
Extend the Phase 13 communications vocabularies so a licence notice can flow as a deduplicated domain event into an in-product notification and a staff email.

Purpose: LIC-07 notices must be deduplicated and carry no sensitive detail, and D-15 requires reusing the Phase 13 pipeline. Many of those vocabularies are compile-time exhaustive, so the additions are one atomic change. Tracer: one `licence.notice` identity is typed, rendered as notification text, linked, rendered as an email and written once through `writeDomainEventOnce`.

Output: additions in six source files, a new `tests/licence-vocabulary.test.ts`, and updated exact-list tests.

Interface contract for later plans (do not rename): domain event type `"licence.notice"`; `writeDomainEventOnce(client, event: DomainEventInput & { id: string }): Promise<boolean>` (true when a row was created); notification type `"staff.licence_notice"` with target type `"STAFF_LICENCE"`; template id `"staff-licence-notice"` with params `{ headline: string; detail: string; licencePath: string }`; allow-listed notification params `noticeKey`, `days`, `expiry`, `graceEnd`; constant `LICENCE_PATH = "/staff/licence"`; `createStaffLicenceResolver(can)`.
