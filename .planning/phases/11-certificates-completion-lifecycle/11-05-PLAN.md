## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff client → template layout persistence | Arbitrary JSON submitted by a browser reaches a `Json` column consumed later by the PDF renderer |
| role grant → institution-wide certificate design | Templates are global, not scoped — anyone with the authoring permission affects every certificate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05 | Elevation of Privilege | Template authoring permission | mitigate | The identifier is the human's recorded 11-DECISIONS.md choice, applied in Task 1 and referenced (not re-decided) in Task 2; acceptance criteria assert no third identifier leaks in |
| T-11-12 | Tampering | Malformed/unrecognised layout JSON persisted | mitigate | `parseCertificateTemplateLayout` runs before the delegate write on both create and update (ASVS V5); the store can never hold a blob the renderer cannot draw |
