<objective>
Close the open UAT gap (test 17): a learner whose certificate is flagged after an attendance or completion correction loses the certificate slot and the download.

Root cause (verified in source): `deriveCertificateColumn` in enrolment-dashboard-service.ts (~L461) returns `not-complete` whenever `hasCompletionRecord` is false, BEFORE it looks at the certificate. An attendance or completion correction supersedes the completion record (that is exactly what triggers the CRD-06 flag), so the flagged certificate's slot renders the deferred "arriving in a future update" copy and the download link is gone, contradicting D-06/CRD-06 ("a flag never withdraws earned access"). The grade-override case passed only because it does not supersede completion.

Fix: check for an existing certificate first (revoked, flagged, active) and only fall back to not-complete / pending-issuance when none exists. `certificateDisplayStatus` stays the single place that ranks revoked over flagged over active. WR-06 (arbitrary row when REVOKED and ACTIVE coexist; `certificateEnabled` false learners seeing "being finalized") is explicitly out of scope and stays logged in 11-REVIEW.md; CR-04 (plan 11-25) removes the normal way those rows coexist.

Output: a reordered pure function, and regression tests that fail against the current ordering.
</objective>
