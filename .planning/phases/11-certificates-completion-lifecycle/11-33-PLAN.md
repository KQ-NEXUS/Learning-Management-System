<objective>
The two steps of this pass that only a human can do.

1. Visual check of generated certificates. Automated tests prove that Yoruba, Polish and CJK names render without error and that the text is recoverable from the PDF, but not that the result looks right. In particular, a Yoruba letter with a tone mark that has no precomposed form (for example ọ́) is drawn as base plus mark without GPOS mark positioning and may sit slightly off; CJK, Arabic and emoji show a "?" by accepted design (plan 11-26). A human must judge whether that is acceptable.

2. Applying the CR-06 migration to shared environments. Plan 11-27 created `prisma/migrations/20260919120000_enrolment_one_live_per_learner_cohort/migration.sql` and proved it only against disposable Testcontainers databases. The `.env` DATABASE_URL points at the remote Neon database; applying a migration to a shared database is a deliberate, human-owned action (it locks the Enrolment table briefly and aborts if duplicate live enrolments exist). The executor must not run it.

Output: two recorded human decisions/results.
</objective>
