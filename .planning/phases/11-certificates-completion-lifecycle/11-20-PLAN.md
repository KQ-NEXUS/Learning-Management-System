Course detail page, and tests. Programme already has `updateProgrammeAction`/edit mode; this plan mirrors it and adds a
component test proving the Programme edit form's certificate settings (previously never exercised).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> updateCourseAction | Public POST endpoint; every field is untrusted, including the template id and courseId |
| updateCourseAction -> courseService | Authorization and audit are enforced here, not in the action |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-80 | Elevation of Privilege | Editing a course without courses.edit | mitigate | `courseService.update` is gated by `courses.edit` at `courseScope(id)`; the edit page also calls `can()` and returns `notFound()`; test asserts AuthorizationError maps to the fixed message |
| T-11-81 | Tampering | Forged or archived certificateTemplateId | mitigate | Server re-resolves via `assertTemplateSelectable` whenever the id changes; the client `<option>` list is never trusted (T-11-33 extended to update) |
| T-11-82 | Tampering | Mass-assignment of unlisted columns (status, slugLockedAt, publiclyListed) | mitigate | `updateCourseSchema` is `.strict()` and `data` is built only from the named fields; test asserts an unknown key is rejected |
| T-11-83 | Repudiation | Certificate policy changed with no trail | mitigate | `courseService.update` writes `course.updated` with before/after and the reason "Edited from the course editor." |
| T-11-84 | Information Disclosure | error.message passthrough to the client | mitigate | Only `TemplateNotSelectableError` and `SlugFrozenError` (user-facing copy) surface a message; auth errors map to a fixed string; unknown errors are rethrown |
| T-11-85 | Tampering | Silent reset of an archived-but-selected template on unrelated edits | mitigate | Changed-only template validation plus disabled-selected archived option; covered by a test |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
</threat_model>
