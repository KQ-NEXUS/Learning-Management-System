<objective>
Close two independent minor UAT gaps that share no files: test 4 (uploaded logo cannot be dragged reliably on the template
canvas) and test 13 (no public place to type a verification reference).

Purpose:
- Test 4 root cause (verified): `TemplateCanvas.tsx` renders the uploaded image as a plain `<img>` (~L350) that is natively
  draggable and pointer-active, so mousedown+move starts the browser's ghost-image drag, which cancels the editor's pointer drag
  (a 100px drag moved 15px). The element boxes also allow text selection and lack `touch-action: none`.
- Test 13 root cause (verified): `src/app/(auth)/verify/page.tsx` owns `/verify` for IAM-02 email verification and is linked from
  already-dispatched transactional emails; Next refuses two pages on one path. 11-06 correctly dropped a bare landing page.
  The fix therefore uses a non-colliding public path, `/verify-certificate`, and leaves the auth page and every emailed link untouched.

Output: A drag-safe canvas with a test that fails against the old markup, and a public `/verify-certificate` entry page with route-collision and
no-caching guards. Note for the SUMMARY: UAT test 13's literal wording ("plain /verify path") cannot be satisfied without breaking IAM-02;
the equivalent outcome is delivered at the new path and the user should re-word the expectation.
</objective>
