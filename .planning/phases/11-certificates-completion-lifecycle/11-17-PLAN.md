<objective>
Close UAT test 10 (BLOCKER): the learner dashboard hides a course exactly when its certificate becomes ACTIVE,
because issuance moves the enrolment to COMPLETED (D-05) and `listOwnActiveEnrolments` filters `status: "ACTIVE"`.

Purpose: CRD-03 says an issued certificate is downloadable by its owner. The download route works; the only
learner entry point to it (the dashboard `CertificateSlot`) is unreachable in the one state where a certificate
is valid and unflagged.

Output: A read-side visibility path for COMPLETED enrolments in `learner-access.ts`, a COMPLETED-aware dashboard
card in `enrolment-dashboard-service.ts`, and regression tests whose fixtures use the status issuance really writes.

DECISION G-01 (planner ruling, recorded here so execution does not re-litigate it): **a COMPLETED enrolment is
VISIBLE but NOT OPERABLE.**
- Visible: it appears on `/dashboard` (progress, certificate slot). The read path opts in explicitly with
  `includeCompleted`; every other caller keeps today's ACTIVE-only behaviour.
- Not operable: no lesson content, no progress/attempt/submission writes. This is already Phase 9's stated rule
  (`hasActiveEnrolmentCoveringCourse`'s doc comment: "a ... COMPLETED enrolment never counts") and it is what
  keeps D-06 safe. A revoke or a CRD-06 flag returns the enrolment to ACTIVE with full access, so nothing is lost;
  a write against a COMPLETED enrolment would instead re-run completion under a certificate that already rests on
  the current record. This plan pins that rule with a test rather than changing it.
- Consequence to disclose: the "Assessments" and "Results" reads (`learner-results-service`, `attempt-service`,
  `submission-service`) share ACTIVE-only ownership resolvers with the write paths, so they are NOT widened here.
  Plan 11-18 therefore hides those two slots on a COMPLETED card rather than showing a false "No results yet".
  Whether completed learners should be able to review results/content is a product question for the user, not a
  planner call; it is out of scope for this gap closure.
</objective>
