Close the data half of UAT test 8 (MINOR): an automatically issued certificate looks identical to a manual one in the staff
issued list. The issuer is only resolved on the detail page (`getCertificateIssuer`), so the list has no Issued-by indicator.

that a certificate appeared on its own. This plan adds the data source and the list column/filter; plan 11-23 adds the landing
page's "Recently issued" section that consumes the same source.

Output: `listCertificateIssuanceSources` in `certificate-service.ts` (one batched, authorized audit read, not N+1 calls to
`getCertificateIssuer`), an "Issued by" column and filter in `IssuedCertificatesTable`, and tests.
No new column on `Certificate` and no migration: the audit row already records the issuer (`certificate.issued` with the staff actor id,
`certificate.issued_auto` with a null actor).

| Boundary | Description |
|----------|-------------|
| staff session -> issuer lookup | Only holders of certificates.view (global, as for the list) may read issuance sources |
| audit table -> staff page | Audit rows carry actor ids; only a display name may cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-91 | Information Disclosure | Actor id/email leaking to the client via the source map | mitigate | Returned shape carries only `{ kind, actorName }`; a test asserts no `actorId` key exists in any value |
| T-11-92 | Elevation of Privilege | Reading audit history without certificates.view | mitigate | Wrapped in `withPermission("certificates.view", ...)` at the same global scope as `certificateService.list({})`; denied-caller test |
| T-11-93 | Repudiation | Mislabelling a certificate as Automatic when no record exists | mitigate | Missing audit row maps to `not-recorded`, displayed "Not recorded"; test asserts it never shows "Automatic" |
| T-11-94 | Denial of Service | Unbounded `IN` list on a large certificate table | accept | One query per page load over the ids the list already returned; the list itself is already unpaginated in this phase, so this adds no new asymptotic cost |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
