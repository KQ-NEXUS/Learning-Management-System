<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff browser → issuance | A click here produces a legally/academically significant credential |
| cross-cohort queue → scoped visibility | One page lists eligible enrolments from every cohort in the institution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-46 | Elevation of Privilege | Issuance from the queue without authority | mitigate | `issueCertificateAction` delegates to `issueCertificateManually`, gated by `certificates.issue` with the enrolment's cohort scope; the action adds no bypass and re-validates its input with a `.strict()` schema |
| T-11-63 | Information Disclosure | Cross-cohort learner names visible to a cohort-scoped staff member | mitigate | `listPendingIssuance` applies `certificates.view` with the caller's `ResourceScope` (plan 11-11, with a sibling-cohort leak test); this page passes the caller's scope straight through and adds no unscoped query |
| T-11-64 | Tampering | A forged `enrolmentId`/`scope` pair submitted directly to the server action | mitigate | `.strict()` zod schema plus the service's own server-side eligibility re-check (an unsuperseded `CompletionRecord` must exist) — the rendered queue is not the authorization |
| T-11-65 | Repudiation | A manual issuance attributed to no one | mitigate | `issueCertificateManually` audits with the staff actor's id, deliberately not `SYSTEM` (plan 11-11) |
| T-11-66 | Denial of Service (usability) | A click that silently does nothing | mitigate | All three non-`issued` outcomes are mapped to distinct actionable messages and asserted by test |
| T-11-38 | Information Disclosure | Raw service errors reaching the browser | mitigate | Fixed message mapping, zero `error.message` pass-through, asserted by grep |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
</threat_model>
