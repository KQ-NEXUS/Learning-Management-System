<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff request → credential lifecycle | Issue, revoke and reissue are the highest-consequence acts in this phase |
| learner request → own certificate file | The download predicate is the only thing between a learner and someone else's credential |
| concurrent staff actions → one certificate row | Two staff members can act on the same certificate simultaneously |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-46 | Elevation of Privilege | Unauthorized issuance | mitigate | `issueCertificateManually` is gated by `certificates.issue` with the enrolment's cohort scope, AND re-checks server-side that an unsuperseded `CompletionRecord` exists — staff sign off on an earned credential, they cannot conjure one |
| T-11-47 | Elevation of Privilege | Unauthorized revocation | mitigate | `revokeCertificate` gated by `certificates.revoke`; denial case asserted |
| T-11-48 | Tampering | Double-revoke or lost-update between two simultaneous staff actions | mitigate | Compare-and-set `updateMany` on `status: "ACTIVE"` with a `count !== 1` typed error, mirroring `GradeChangedError` |
| T-11-49 | Repudiation | Revocation with no recorded justification | mitigate | 10-character mandatory reason enforced before any write, persisted to `revocationReason`, and carried on the audit row with before/after (CRD-05) |
| T-11-50 | Information Disclosure | Staff-internal revocation reason reaching the public verify page or a Phase 13 email | mitigate | The reason is persisted on the row but excluded from every domain-event payload; asserted by key-set checks on the recorded events. Plan 11-06 already excludes it from the public `select` |
| T-11-51 | Information Disclosure | A learner downloading another learner's certificate | mitigate | `getOwnCertificateForDownload` matches on the certificate's `userId` and returns `null` — never throws, never varies its return by reason — so the route renders one indistinguishable 404 |
| T-11-52 | Tampering | Reissue momentarily violating the one-active-certificate index | mitigate | Ordered transaction: the old row leaves `ACTIVE` before the new row is inserted, asserted via recorded call order |
| T-11-53 | Tampering | History rewritten on reissue | mitigate | The old row's reference, file, dates and reason are asserted untouched; nothing is deleted (CAT-08, CRD-05) |
| T-11-54 | Spoofing | A superseded credential still verifying as valid | mitigate | The old row moves to `SUPERSEDED`, which plan 11-06 maps to the public `revoked` outcome |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
</threat_model>
