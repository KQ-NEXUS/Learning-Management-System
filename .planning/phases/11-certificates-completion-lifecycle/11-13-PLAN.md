<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated learner → certificate file | The ownership predicate is the only control between a learner and any certificate |
| anonymous request → download route | The route must not disclose which certificate ids exist |
| presigned URL → object store | Once resolved, the URL grants direct read access outside the application |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-51 | Information Disclosure | A learner downloading another learner's certificate | mitigate | `getOwnCertificateForDownload` matches on `userId` and returns null; the route's staff branch requires `certificates.view` in matching scope |
| T-11-59 | Information Disclosure | Download route acting as an existence oracle | mitigate | Every non-success outcome is a 404 with an empty body; the not-yours and does-not-exist cases assert byte-identical responses and header sets. No 401 or 403 is ever emitted (RBAC-06 / T-09-03 denial parity) |
| T-11-10 | Information Disclosure | Leaked presigned URL replayed | mitigate | 60-second FILE-class TTL from `upload-limits.ts`, plus `Cache-Control: private, no-store` on the hand-built 302 so no shared cache retains the resolved location |
| T-11-24 | Spoofing | Next 16 Cache Components serving a stale 302 or a dead presigned URL | mitigate | No `dynamic`/`revalidate`/`fetchCache`/`'use cache'` anywhere in the route; the Prisma read defers it to request time per the docs read in Task 1 (Pitfall 6) |
| T-11-60 | Information Disclosure | A revoked credential still downloadable | mitigate | `getOwnCertificateForDownload` returns null for `REVOKED`, so the route 404s and the dashboard renders no link (UI-SPEC §7.6 branch 5) |
| T-11-61 | Information Disclosure | Another learner's certificate surfacing on a dashboard | mitigate | The certificate lookup rides the dashboard's existing ownership-scoped aggregate query; a dedicated test asserts cross-learner absence |
| T-11-62 | Denial of Service | Null `storageKey` causing a 500 | mitigate | Treated as a 404, asserted as its own behavior |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
</threat_model>
