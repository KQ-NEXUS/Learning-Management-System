## Trust Boundaries

(The plans list 70 finer-grained boundaries; these are the ten that matter.)

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Public internet -> verification pages | /verify/[ref] and /verify-certificate are unauthenticated and cache-free; the service selects exactly status, learnerName, awardTitle, issuedAt | Verification reference (128-bit); learner name and award title |
| Browser -> certificate download route | Owner or in-scope staff only; every denial is an identical 404; 60 s presigned URL, private/no-store | Certificate id; presigned object URL; PDF bytes |
| Staff browser -> server actions | Issue, revoke, reissue, template, asset, course/programme edit actions behind withPermission with .strict() zod input | Reasons, template layouts, issuance settings |
| Learner/attendance write -> issuance transaction | Row + COMPLETED transition + audit + event inside the caller transaction; PDF rendered and stored after commit (database-only issuance) | Enrolment/completion state, certificate row |
| Untrusted layout JSON -> parser -> renderer | Pure versioned parser; sanitiser makes any text render without throwing; image keys confined to certificate-template-assets/ | Template layout, learner-supplied names |
| Uploaded template image -> object store -> renderer | PNG/JPEG only, verified staged upload, SVG excluded, magic-byte guard in the renderer | Image bytes |
| Certificate row -> post-commit file service -> object store | Never throws, compare-and-set on storageKey, bounded settle, on-demand recovery after authorization | Generated PDF, storage keys |
| Operator/CLI -> shared database | CR-06 migration with duplicate preflight; applied to a Neon branch then main by the orchestrator at the user's direction (recorded deviation, 11-33-SUMMARY.md) | Enrolment index DDL |
| Supply chain -> repository | Only pdf-lib and @pdf-lib/fontkit added (human-vetted, 11-02); Noto Sans is a hash-pinned committed asset (human-approved, 11-26) | npm packages, font binary |
| Grade/attendance/completion correction -> certificate flag | Flag-only (reviewFlaggedAt), enrolment reverted via the state machine, audited; certificates are never deleted | Correction events |
