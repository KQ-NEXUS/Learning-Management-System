<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| completion engine → credential issuance | A system-triggered write creates a legally/academically significant document with no human in the loop |
| concurrent transactions → Certificate table | Two triggers may race for the same enrolment and scope |
| certificate row → enrolment status | Issuance is the only thing permitted to move an enrolment to COMPLETED |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | Duplicate certificate under concurrent completion triggers | mitigate | Create-first ordering so the partial unique index arbitrates before any rendering work; `isUniqueConstraintViolation` (P2002) mapped to the `already-issued` outcome, with a dedicated test case (Task 1) |
| T-11-27 | Elevation of Privilege | Unauthorized issuance via a route-reachable export | mitigate | This module exports no function a route handler can call with a caller-supplied enrolment id; the staff-facing gate lives in `certificate-service.ts` (plan 11-11), and the system path is reached only from `reactToCompletionResults` inside an already-permission-gated request (Pattern 3) |
| T-11-28 | Spoofing | A Programme-cohort learner obtaining Course certificates for member courses | mitigate | D-01 enforced structurally: `issueCertificateForEnrolment` refuses `scope: "COURSE"` when the cohort carries a `programmeId`, AND `reactToCompletionResults` skips every `COURSE` result for a Programme cohort. Two independent guards, each with its own test case |
| T-11-29 | Repudiation | A certificate issued with no attributable actor | mitigate | Every issuance writes an audit row: `actorId: null, actorType: "SYSTEM"` for the reactive path (matching the checkout-webhook precedent), the real actor id for a staff-triggered call |
| T-11-30 | Tampering | A correction silently destroying or altering an issued credential | mitigate | The superseded branch sets `reviewFlaggedAt` only; `status`, `verificationRef`, `issuedAt` and `storageKey` are asserted untouched (CRD-06) |
| T-11-31 | Tampering | Enrolment reaching COMPLETED with no credential behind it | mitigate | The status write happens only after a `Certificate` row exists, and goes through `assertTransition` rather than a bare update |
| T-11-32 | Information Disclosure | PDF bytes leaking into the domain-event outbox (drained by Phase 13 email) | mitigate | The `certificate.issued` event payload is restricted to ids, scope and `verificationRef`; asserted in Task 1's behavior list |
| T-11-SC | Tampering | npm installs | mitigate | This plan installs nothing; `git diff package.json` must be empty |
</threat_model>
