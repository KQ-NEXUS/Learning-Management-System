the Route Handler, and per-type fields for all eight lesson types.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff browser → save action | Editor output is HTML; a Server Action is a public POST endpoint and the client's sanitisation proves nothing. |
| staff browser → upload route | Files of arbitrary size and type. |
| stored embed URL → learner iframe | An embed URL becomes an iframe `src` on the learner page. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-47 | Tampering | stored XSS via pasted or POSTed HTML | mitigate | `parseLessonInput` runs `sanitizeLessonBody` server-side on every write; the editor's restricted extension array reduces the surface but is never the control; checkpoint step 4 exercises the POST path via paste |
| T-04-48 | Elevation of Privilege | H1/colour/font injection defeating the document outline | mitigate | The extension array omits those nodes entirely, so the commands do not exist; grep asserts no colour/font extension is registered |
| T-04-49 | Tampering | off-allow-list embed host | mitigate | `parseEmbedUrl` exact-host check server-side (plan 04-04); the form hint names the allow-list so staff are not guessing; checkpoint step 5 |
| T-04-50 | Denial of Service | video upload through a Server Action | mitigate | `UploadPanel` posts to the Route Handler with a streamed body; grep asserts no `FormData` and no `"use server"` in that component; checkpoint step 7 uses a >5 MB file |
| T-04-51 | Information Disclosure | infected file offered for download in the staff UI | mitigate | The INFECTED branch renders no download control; the download route refuses independently |
| T-04-52 | Information Disclosure | error text distinguishing "not found" from "not yours" | mitigate | `AuthorizationError` maps to `notFound()` on pages and to a generic failure in actions, matching the established pattern |
</threat_model>
