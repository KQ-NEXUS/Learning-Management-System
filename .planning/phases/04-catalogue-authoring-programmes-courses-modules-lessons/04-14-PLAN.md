<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored lesson row → rendered HTML | The database is not a trusted source: a row may predate a sanitiser fix or have been written by a path since removed. |
| stored embed URL → iframe | An iframe from an attacker-chosen origin is stored XSS and clickjacking. |
| preview URL → anonymous visitor | A preview link that leaks would reveal unpublished content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-62 | Tampering | stored XSS from a pre-existing dirty row | mitigate | `sanitizeLessonBody` runs again at render (D-30); component test asserts a stored `<script>` never reaches the output |
| T-04-63 | Elevation of Privilege | iframe from a non-allow-listed origin | mitigate | `parseEmbedUrl` re-run on the STORED value at render; a failing value renders a fallback and no iframe; `sandbox`, `referrerPolicy="no-referrer"` and a `title` on every iframe |
| T-04-63b | Denial of Service | video playback stalling partway because the signed URL expired mid-session | mitigate | Per-type TTL (D-37): 4h for VIDEO, 60s for FILE/IMAGE, set in `src/lib/upload-limits.ts` and asserted by a route test that the two values differ; checkpoint step 10b plays past the tight window and seeks into unbuffered video |
| T-04-64 | Tampering | serving an unscanned or infected file | mitigate | The renderer offers no download control unless `scanStatus === "CLEAN"`, and the download route refuses independently (plan 04-07) — two gates, neither relying on the other |
| T-04-65 | Information Disclosure | preview URL revealing unpublished content | mitigate | No preview tokens and no shareable links (D-13); both routes gate on `courses.view` and map denial to `notFound()`. An anonymous visitor gets the existing `src/app/staff/layout.tsx` sign-in redirect — identical for every staff URL, real or invented, so it carries no signal; a signed-in but out-of-scope caller gets 404. Checkpoint step 15 verifies both |
| T-04-66 | Denial of Service | render-path bundle blowing the NFR-02 budget | mitigate | `LessonContent` is a Server Component with no client directive and no `@tiptap/*` import, grep-asserted and confirmed by checkpoint step 11 |
</threat_model>
