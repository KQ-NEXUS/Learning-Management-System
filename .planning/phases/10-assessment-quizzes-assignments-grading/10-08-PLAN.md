## Trust Boundaries

| Boundary | Description |
|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-07 | Elevation of Privilege | assessment routes and actions | mitigate | Every read and write goes through `assessmentService` / `publishAssessment`, which resolve scope via `assessmentCourseScope` on the row. Route files import no `@prisma/client`, enforced by an AST assertion in the test |
| T-10-13 | Tampering | `feedbackBehaviour` and numeric settings | mitigate | Server actions parse input with `zod` against `FEEDBACK_BEHAVIOURS` and numeric bounds before calling the service, and the service re-validates — the browser control is never the only check |
| T-10-14 | Tampering | publish path | mitigate | `publishAssessmentAction` surfaces the service's blocking readiness items; the UI cannot publish past them because the refusal happens server-side, and the panel renders the same evaluator's output |
| T-10-25 | Information Disclosure | out-of-scope Course | mitigate | An authorization failure surfaces as a denial rather than an empty list, so a staff member cannot infer that another Course has no assessments |
| T-10-SC | Tampering | npm installs | accept | No package installs; `lucide-react` is already present and was human-vetted in Phase 04.1 |
</threat_model>
