<objective>
Write the pure scoring core for ASM-02: a module with zero runtime imports that turns a frozen
question snapshot plus a learner's raw option selections into a reproducible score, and that selects
which of several attempts is the effective one per D-02's `attemptGradingMethod`.

Purpose: ASM-02 requires "reproducible calculation." Reproducibility is only provable if the
calculation is a pure function of its inputs — no database read, no clock, no permission check.
Isolating it here also keeps it off every request closure `tests/boundary.test.ts` walks.
Output: `quiz-scoring.ts` and an exhaustive `tests/quiz-scoring.test.ts`.
</objective>

<!-- Contract that plan 10-06 (attempt submit/score) consumes. Define it here first. -->

`QuestionType` is a closed Prisma enum with exactly three members: `SINGLE_CHOICE`, `MULTI_CHOICE`,
`TRUE_FALSE`. All three are objectively auto-scorable; there is no manual-grading path for a quiz
question.

Snapshot shape this module receives (produced by plan 10-04's `startAttempt`, frozen into
`Attempt.answers` JSON):
- `OptionSnapshot`: `{ id: string; position: number; label: string; isCorrect: boolean }`
- `QuestionSnapshot`: `{ id: string; position: number; prompt: string; type: "SINGLE_CHOICE" | "MULTI_CHOICE" | "TRUE_FALSE"; marks: number; explanation: string | null; options: OptionSnapshot[] }`
- `AttemptResponse`: `{ questionId: string; selectedOptionIds: string[] }`
- `AttemptScore`: `{ score: number; maxScore: number; passed: boolean | null; perQuestion: Array<{ questionId: string; awarded: number; marks: number; correct: boolean }> }`
</interfaces>

  <behavior>
    - SINGLE_CHOICE: exactly one selected option id that is `isCorrect` awards full `marks`; anything else (wrong option, zero selections, more than one selection) awards 0
    - TRUE_FALSE: scored identically to SINGLE_CHOICE
    - MULTI_CHOICE with marks M, C total correct options, S correct selected, W incorrect selected: awards `M * max(0, (S - W) / C)`
    - MULTI_CHOICE selecting all C correct and zero incorrect awards exactly M
    - MULTI_CHOICE selecting 2 of 3 correct and zero incorrect awards `M * 2/3`
    - MULTI_CHOICE selecting 2 of 3 correct and 2 incorrect awards 0 (never negative)
    - MULTI_CHOICE selecting zero options awards 0
    - A question with zero correct options (an authoring defect) awards 0 and never divides by zero
    - A `selectedOptionIds` entry naming an option id not present in that question's snapshot is ignored, never counted as correct and never throwing
    - A `selectedOptionIds` entry naming a question id not present in the snapshot is ignored entirely
    - A question in the snapshot with no matching response is scored as unanswered (0 awarded, still contributes its `marks` to `maxScore`)
    - `maxScore` is the sum of every snapshot question's `marks`, independent of what the learner answered
    - Duplicate option ids in one `selectedOptionIds` array count once, not twice
    - `passed` is `score >= passMark` when `passMark` is a number, and `null` when `passMark` is null
    - Scoring the same snapshot + responses twice returns deeply equal results
  </behavior>
  <action>
