<objective>
Deliver the narrow WebVTT caption scope approved in plan 15-01, so lesson video has an accessible media alternative (NFR-09): data model, upload kind, authorised delivery and the learner player track.

Purpose: 04.1-CAPTIONS-SCOPE.md set out the ready scope: a scanned WebVTT resource linked to a video, language and label metadata, authorised delivery and a player track. A track element cannot follow a cross-origin redirect to object storage without bucket CORS changes, so captions are served same-origin through a small, authorised, uncached route (caption files are at most 1 MB); video keeps its presigned redirect. Staff authoring is plan 15-24.

Output: an additive migration with the [BLOCKING] push, the CAPTION upload kind, service support, the captions route, the player and content changes, and tests.

Ownership: src/components/catalogue/LessonMediaPlayer.tsx and src/components/catalogue/LessonContent.tsx are catalogue components shared with the co-worker and share one row in 15-DECISIONS.md "Shared UI ownership"; Task 2, the only task that edits them, carries a precondition that halts until that row reads "agreed". Tasks 1 and 3 edit the schema, a new migration, upload limits, the lesson resource service, a new route and tests, none of which is shared UI.
</objective>
