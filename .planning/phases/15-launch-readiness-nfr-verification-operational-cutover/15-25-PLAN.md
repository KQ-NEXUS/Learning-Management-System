<objective>
Build the registry-driven authorization bypass suite D-09 asks for: an inventory of every server action and route that a test keeps complete, and a matrix that calls each one as the wrong people on a real database.

Purpose: NFR-05 requires tests covering direct-request bypass attempts for all protected operations and private downloads. Server actions are public POST endpoints reachable by anyone (Next server-actions guide). The existing licence registry is per service file and cannot enumerate actions (RESEARCH Pitfall 3), so this plan builds the action and route inventory with the same pattern and AST tooling. Wrong scope and wrong record state across all scoped actions are plan 15-26; private-file headers, TTLs and webhooks are plan 15-27.

Output: the registry, inputs and matrix harness, the inventory guard, the payments tracer, the generic matrix and its evidence.

Edge coverage disposition: NFR-05 adjacency, empty and ordering rows are explicit truths above; NFR-05 concurrency is in plan 15-26.
</objective>
