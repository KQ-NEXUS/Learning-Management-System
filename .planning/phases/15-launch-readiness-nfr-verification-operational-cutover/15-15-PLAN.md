<objective>
Stand up the browser test harness and prove the first leg of the unassisted journey end to end: discover, register, verify, sign in (D-08).

Purpose: Playwright is not installed; the stub email transport discards the raw verification token, which exists only in the email, so an automated register-then-verify step is impossible today (RESEARCH A3, Pitfall 8). Scheduled functions do not run locally or on deploy previews (Pitfall 9), so a guarded task runner is added for later journey legs and the staging run.

Output: installed Playwright and axe packages, the email seam, the capture server, the Playwright config, a task runner, and journey leg one.

Package legitimacy: @playwright/test and @axe-core/playwright are rated OK and approved in 15-RESEARCH.md "Package Legitimacy Audit", so no human legitimacy checkpoint is needed; no SUS package is installed by this plan.
