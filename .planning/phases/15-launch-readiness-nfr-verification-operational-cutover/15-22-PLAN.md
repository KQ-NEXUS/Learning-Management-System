## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff browser to privacy server actions | Public POST endpoints that export or rewrite personal data |
| staff browser to /staff/privacy lookup | Exact-match search over learner identifiers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-22-01 | Elevation of privilege | direct POST to privacy actions | high | mitigate | Actions delegate to withPermission-gated services; zod strict input; the bypass suite covers them (plan 15-25) |
| T-15-22-02 | Information disclosure | account enumeration through the lookup or record URL | medium | mitigate | One no-match message for unknown, staff and malformed input; notFound() for denials and unknown ids |
| T-15-22-03 | Tampering | anonymising the wrong learner | high | mitigate | Typed email check, 20-character reason, server re-check of the target id, danger modal |
| T-15-22-04 | Information disclosure | learner email in the GET query string and host logs | low | accept | UI-SPEC S2 approves a GET form; the URL drops the value after a match (redirect); staff-only page behind a Global permission |
| T-15-22-05 | Repudiation | privacy actions | low | mitigate | Service audit rows (plans 15-16, 15-21) |
</threat_model>
