<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| browser → object storage | forged MIME/size or active content | closed allow-list plus HEAD equality before READY |
| attachment id → download | object-id guessing reveals private/internal file | owner/staff authorization and denial-parity 404 |
| scheduled worker → data | unbounded or overbroad cleanup deletes valid files | fixed age/status predicate, bound, defensive re-filter and audit |

**Disposition:** Mitigate every listed threat through the named implementation control; none are accepted or transferred.

| ID | Category | Severity | Mitigation |
|---|---|---|---|

| T-12-05 | Information Disclosure/Tampering | HIGH | private random keys, short presigns, exact metadata checks, READY only |
| T-12-06 | Denial of Service | HIGH | 3-file/10 MiB caps, 900-second intent, bounded cleanup |
</threat_model>
