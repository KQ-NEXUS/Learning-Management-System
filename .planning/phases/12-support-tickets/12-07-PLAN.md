<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| public/internal composer UI → command | operator sends private text publicly | separate entry components plus mandatory public review |
| visible action → server mutation | presentation permission treated as authority | fresh actor + service tickets.manage on every action |
| stale browser → current ticket | overwrites another agent's triage | expectedVersion and explicit conflict refresh/review |

## STRIDE Threat Register

**Disposition:** Mitigate every listed threat through the named implementation control; none are accepted or transferred.

| ID | Category | Severity | Mitigation |
|---|---|---|---|
| T-12-01 | Information Disclosure | CRITICAL | separate composers, persistent Staff only treatment and public review |
| T-12-02 | Elevation of Privilege | HIGH | read/manage split checked server-side |
| T-12-04 | Tampering | HIGH | no optimistic mutation; stale conflict requires reviewed retry |
| T-12-07 | Repudiation | HIGH | mandatory reasons and attributed chronology |
</threat_model>
