<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| server projection → learner client | Internal rows leak before React filtering | separate database projection selecting PUBLIC only |
| ticket permission → target domain | Support agent gains grades/payments/profile access | independent target authorization and locked projection |
| concurrent commands → aggregate | stale assignment/status overwrites newer work | expected version plus state predicate in updateMany |
| transaction → Phase 13 outbox | private content becomes notification payload | closed minimal event payloads and sink redaction |

## STRIDE Threat Register

**Disposition:** Mitigate every listed threat through the named implementation control; none are accepted or transferred.

| ID | Category | Severity | Mitigation |
|---|---|---|---|
| T-12-01 | Information Disclosure | CRITICAL | structurally separate learner/staff DTOs and database visibility predicate |
| T-12-02 | Elevation of Privilege | HIGH | GLOBAL tickets permissions only; integration proof of unrelated denials |
| T-12-03 | Elevation of Privilege | HIGH | target service reauthorization for every context href |
| T-12-04 | Tampering | HIGH | version CAS, typed conflict and append-only event/audit transaction |
| T-12-07 | Repudiation | HIGH | actor, time, before/after and mandatory reasons in TicketEvent/AuditEvent |
</threat_model>
