**Tracer.** Wire one NGN payment path through every layer this phase touches — cohort card CTA,
currency-carrying checkout intent, order snapshot, provider-neutral initiation interface, Paystack
split initialization, signature-verified webhook, shared settlement transition — and prove it end to

NGN/Paystack slice on one path first means an architectural dead end (a snapshot shape that does not
survive the transaction, a settlement service that cannot be made provider-neutral, an isolation gate
that cannot be generalized) surfaces after one plan instead of after six. Everything from 07-05
onward expands outward from this proven slice.
Output: a working, production-quality NGN rail with real error handling on the single path.
</objective>
