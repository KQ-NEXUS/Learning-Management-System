Create `src/server/payments/pricing.ts` exporting:

```
export const PLATFORM_FEE_BPS = 150;
export type SupportedCurrency = "NGN" | "USD";
export type GatewayFeeScheduleValues = {
  provider: "PAYSTACK" | "STRIPE" | "MANUAL";
  currency: SupportedCurrency;
  version: number;
  percentageBps: number;
  fixedMinor: number;
  waiverThresholdMinor: number | null;
  capMinor: number | null;
  taxBps: number;
  roundingRule: string;
};
export type PricingInput = { baseAmountMinor: number; platformFeeBps?: number; schedule: GatewayFeeScheduleValues };
export type CheckoutBreakdown = {
  baseAmountMinor: number;
  platformFeeMinor: number;
  gatewayFeeEstimateMinor: number;
  totalAmountMinor: number;
};
export class InvalidFeeScheduleError extends Error { ... }
export class MoneyOverflowError extends Error { ... }
export function calculatePlatformFeeMinor(baseAmountMinor: number, bps?: number): number;
export function calculateCheckoutBreakdown(input: PricingInput): CheckoutBreakdown;
```

Implementation requirements, each of which the Task 1 tests already pin:

- `calculatePlatformFeeMinor` is `roundHalfUp((baseAmountMinor * bps) / 10_000)` implemented with
  integer arithmetic — multiply first, then divide with an explicit half-up adjustment
  (`Math.trunc((n * bps + 5_000) / 10_000)` style), so no intermediate value is a fraction of a minor
  unit carried through a later multiplication.
- Guard every multiplication with a safe-integer check and raise `MoneyOverflowError` before
  producing a wrong number. A silent wrong amount is worse than a thrown error on a page that can
  show a support route.
- Reject a schedule whose combined effective rate (`percentageBps + taxBps`) is at or above 10000, or
  whose `fixedMinor`/`capMinor`/`waiverThresholdMinor` is negative, with `InvalidFeeScheduleError`.
- Apply the waiver threshold first (omit `fixedMinor` when the pre-gross subtotal is below it), then
  compute the uncapped gross-up, then clamp to `capMinor`, then round up once. Clamping after the
  final rounding would add a rounding remainder on top of a cap that is supposed to be exact.
- `gatewayFeeEstimateMinor = totalAmountMinor - baseAmountMinor - platformFeeMinor` is the definition,
  not a second independent calculation — computing it twice is how the two drift apart.
- The module's header comment states, in prose, that this file imports nothing and why: it is called
  from both provider adapter directories, and any provider or Prisma import here would break the
  PAY-09 isolation scan 07-04 generalizes.
