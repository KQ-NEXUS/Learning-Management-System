<objective>
Let an enrolled learner reach lesson content through the existing presigned-URL pipeline by adding a
second, ownership-based authorization predicate — without duplicating the upload-status checks, the
signer, the TTL policy, or the 404 parity the staff path already has.

Purpose: LRN-03 requires authorized file access for learners. The route exists and works, but its
only predicate today is `courses.view`, which an enrolled learner legitimately does not hold.
Output: one new service export, one extended route handler, tests for both.
</objective>
