<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| direct URL navigation → lesson content | A learner can type any lesson id into the address bar |
| Server Action POST → progress write | A public entry point reachable without the UI |
| lesson HTML body → rendered page | Stored HTML is rendered with `dangerouslySetInnerHTML` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02 | Tampering | Server Actions | mitigate | Both actions resolve `getCurrentActor()` and pass only the session actor to the service; the service re-runs `assertLessonOpenable`. No identity field is read from `FormData`, asserted by a grep gate and a planted-field test |
| T-09-34 | Elevation of Privilege | Direct URL to a locked lesson | mitigate | The page calls `assertLessonOpenable` before any content read and maps `locked` to `notFound()` — the UI lock is not the gate |
| T-09-38 | Information Disclosure | Closed access window | mitigate | `access-window-closed` renders the ended panel INSTEAD of content; a test asserts no body text appears in that render |
| T-09-39 | Cross-site scripting | `LessonContent` body rendering | mitigate | Inherited and unchanged: `LessonContent` runs `sanitizeLessonBody` as a second pass at render time (D-30). This phase edits neither that file nor the sanitiser — enforced by an empty-diff gate |
| T-09-03 | Information Disclosure | Learner resource listing | mitigate | DD-26 — a second ownership predicate on the same shaping body; `listLessonResources`'s `courses.view` requirement is not widened |
| T-09-40 | Repudiation | Self-undo | accept | D-13 explicitly frames self-undo as the learner's own non-audit-sensitive record; an audit row is still written (09-06) with `reason: null` |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages this phase |
</threat_model>
