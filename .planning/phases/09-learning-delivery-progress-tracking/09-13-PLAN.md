| path parameters → cohort/enrolment pairing | `cohortId` and `enrolmentId` are independently caller-supplied |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-44 | Tampering | Cross-cohort enrolment id | mitigate | The page verifies the `enrolmentId` belongs to the path's `cohortId` and `notFound()`s otherwise; asserted by a test |

| T-09-45 | Information Disclosure | Staff denial leaking record existence | mitigate | `AuthorizationError`/`AuthenticationError` both map to `notFound()`, matching the staff area's existing convention |
