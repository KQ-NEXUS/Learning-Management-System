## Decisions Made

- Used CSS-only aspect-ratio wrappers for broken media. Conditional error copy would require client-side load handling and violate the zero-client-JavaScript lesson contract.
- Kept the native `<video>` source, preload mode, captions slot and head comment unchanged; no cross-origin attribute, cache-busting query parameter or player replacement was introduced.
- Kept UploadPanel's shared `StatusPill` consumption and all server-response reconciliation paths unchanged.
