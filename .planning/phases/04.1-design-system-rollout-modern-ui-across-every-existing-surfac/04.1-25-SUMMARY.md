## Decisions Made

- **D-21 beats UI-SPEC §7.2 prose.** UI-SPEC §7.2 text says the right-column inner stack is `gap: 16px` ("mockup's raw 20px snapped to the md tier"). CONTEXT D-21 and `tests/unit/design-contract.test.ts` `LOCKED_EXCEPTIONS` both say 20px (`gap-5`). Per the plan's own instruction ("Higher-priority D-21 requires 20px auth form-stack gap … do not snap them to the lower-priority grid") and "CONTEXT overrides contradictory UI-SPEC", the stack wrapper is now `gap-5`. This is the exact file + token the test allow-lists.
- **Form-internal field gaps left at `gap-4` (16px).** D-21's 20px is the title-to-form / stack gap owned by `layout.tsx`; the `<form>`'s own between-field gap stays on the 16px grid role (unchanged, already compliant).
- **`px-4` (16px) not `px-2` (8px) for controls.** Matched the `ResourceForm` primitive's `px-4 py-2` control role from plan 04.1-24 rather than the "8px compact control padding" role, since these are standard 38px form inputs, not compact controls.
