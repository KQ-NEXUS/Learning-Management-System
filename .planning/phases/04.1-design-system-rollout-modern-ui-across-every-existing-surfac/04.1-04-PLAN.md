## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authorization decision → rendered `denied` branch | `ResourceForm` and `DetailLayout` both render a denied state that must reveal nothing about the record behind it |
| user intent → integrity action | `ConfirmModal`'s reason gate is the last barrier before a refund, grade override, attendance correction or certificate revocation is recorded |
| untrusted field input → rendered validation output | Existing validation logic is untouched; only the rendering of its output changes |
