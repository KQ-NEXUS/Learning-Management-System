### `src/app/globals.css` (config, transform)

**Analog:** itself — `src/app/globals.css` (current, full contents below; this is what gets replaced)

```css
  --color-foreground: var(--foreground);

  --color-accent-contrast: var(--accent-contrast);

```

**Pattern to preserve:** the `:root` → `@theme inline` two-step binding (Tailwind v4 CSS-first
config, no `tailwind.config.js`); the `--font-sans`/`--font-mono` indirection so a font swap is a
one-line edit; the `:focus-visible` global rule (keep the mechanism, only its `outline-offset`
value changes 2px→3px per UI-SPEC §5.3); the reduced-motion media query (verbatim, untouched).
**New tokens to add** (full token chain is pasted ready-to-use in `04.1-UI-SPEC.md` §5.3 — do not
re-derive it, copy it verbatim): primitive tier (raw hex, never referenced by components), semantic
tier (`--ink`, `--muted`, `--line`, `--paper`, `--surface`, `--surface-2`, `--input-border`,
`--color-teal`/`--color-teal-fill`, `--color-green`, amber pair, `--sidebar-*` sub-tier,
`--pill-*` sub-tier). Danger keeps the exact current values (`#b42318`/`#fdf3f2`) — no change there.
