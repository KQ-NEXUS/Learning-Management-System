## Planner Assumptions

- **The broken-media fallback is a placeholder block, not a captioned error.** UI-SPEC section 8.13
  describes "a neutral placeholder block with a short caption". The caption half cannot be delivered
  here: rendering it conditionally on a load failure requires an error event handler, which requires
  a client directive, which UI-SPEC section 10 and D-30/NFR-02 forbid on this component; rendering it
  unconditionally would show an error message beneath media that loaded perfectly well. The plan
  therefore delivers the placeholder block — which is what closes the actual gap, an invisible hole
  where media should be — and records the caption as not delivered rather than pretending otherwise.
  If the caption is wanted later, it needs a deliberate decision about admitting client JavaScript to
  lesson pages, which is a bigger question than a restyle should settle.
- **`LessonContent`'s long-body handling is not addressed.** D-25 explicitly defers the absence of a
  length cap, table of contents or progressive reveal to Phase 9 (Learning Delivery). Recorded here
  so the omission reads as the decision it is.
- **All six bespoke components are RECONCILE, none deferred.** ROADMAP criterion 6 permits an
  explicit deferral with a reason; UI-SPEC section 10's verdict is RECONCILE for all six, and plans
  12 and 13 between them deliver that. The two D-25 behaviour additions inside them are sized as
  their own tasks rather than folded into restyle work.
