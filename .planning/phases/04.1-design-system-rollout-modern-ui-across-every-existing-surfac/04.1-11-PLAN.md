restyle unchanged.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff intent → granted permission | The roles screens are where a staff user decides who can do what; what those screens display is what the user believes they are granting |
| authorization decision → denied panels | Both areas render denied states that must reveal nothing about the record behind them |
| staff input → programme composition | The programme form and arrange screen submit which Courses a programme reuses and in what order |

| T-04.1-30 | Tampering | Programme composition form and arrange wrapper | medium | mitigate | Field names, submitted shape, server-action calls and the unsaved-order dirty signal are all asserted unchanged, with the programme and reorder service tests as the verify |
