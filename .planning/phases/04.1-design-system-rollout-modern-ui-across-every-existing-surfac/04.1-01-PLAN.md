<objective>
Land the spine of the design system: the three-tier token chain in `globals.css`, the two new
typefaces, the mechanical NFR-09 contrast gate, and the one new dependency.

Purpose: this is the tracer slice. Because every component in this codebase already consumes colour
through semantic utility names (`bg-accent`, `text-danger`, `bg-danger-surface`, `text-success`,

zero components carry a raw hex, changing the values behind those names moves all 30 routes onto the
new palette, ground, radius, shadow and type stack in one commit. Nothing below this can be visually
verified until it lands, and every other plan in this phase depends on it.

Output: a rewritten `globals.css`, a re-wired root layout, a new contrast test that reads its inputs
from `globals.css` itself, and `lucide-react` installed behind a human legitimacy gate.
