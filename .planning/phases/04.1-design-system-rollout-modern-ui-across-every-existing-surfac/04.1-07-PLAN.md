<objective>
Give the public catalogue and `/account` one shared learner shell, and widen `/account` off its
narrow auth-style column onto that shell.

Purpose: `/account` currently repeats the same centred wrapper the auth pages do, which the mockup
contradicts — it draws the account screen wide, on the same chrome as the catalogue. D-23 settles
that. The hard constraint is that the two route groups guard differently: the public layout has no
auth guard at all and must keep none, while the account layout has exactly one and must keep it.
That asymmetry is why this is one shared component instantiated twice rather than one shared layout
file.

Output: a new `LearnerShell` component, two layouts that instantiate it while keeping their own guard
logic, and a widened two-column account page.
</objective>
