# Phase 04.1 Plan 16: Keyboard-safe navigation and approved brand mark

The staff sidebar now isolates closed mobile navigation and manages focus through opening, dismissal and resizing. All three shells display the approved two-path glyph inside the existing semantic gradient.

## Accomplishments

- Closed mobile aside is inert and aria-hidden; desktop navigation remains accessible. The media-query listener is removed on unmount.
- Opening focuses the first navigation link and temporarily makes the content sibling inert. Tab and Shift+Tab wrap in the drawer; Escape, backdrop, same-route clicks and route changes close it and restore trigger focus.
- Resizing to desktop releases isolation without moving focus onto the hidden trigger; shrinking to mobile moves sidebar focus back to the trigger. Existing background inert state is preserved on close and unmount.
- BrandMark renders the exact mockup paths with currentColor stroke, aria-hidden and focusable=false. Staff and learner retain their 26px mark, auth retains its 28px mark; adjacent wordmarks retain accessible naming. Auth layout gains no client directive.
