# Phase 04.1 Plan 24: Primitive Visual Contract & Source Gate Summary

**A TypeScript-compiler-API source-contract test that grades every font-size/weight and margin/padding/gap utility in the phase visual manifest against the UI-SPEC role scale, plus the four shared primitives snapped to those roles with all interaction behavior preserved.**

## Accomplishments

- `tests/unit/design-contract.test.ts` — reads each owned source file with the installed `typescript` parser, extracts `className` literals + the string branches of their ternaries/template literals + UPPER_CASE class constants, strips Tailwind variant prefixes (`sm:`, `hover:`, `aria-[invalid=true]:`, …), and asserts every type utility resolves to 25/16/14/11px (primitives) and every spacing utility to the 4/8/16/24/32/48/64 grid.
- Excludes, with explicit rationale in code: `size-`/`h-`/`w-`/`min-`/`max-` sizing, `inset`/`left`/`top` positioning, negative nudges, `sr-only`, colour/alignment `text-*`, radius/shadow/tracking, and authored HTML strings.
- Locked-exception allowlist for D-21 (`gap-5` only in `src/app/(auth)/layout.tsx` / `AuthPanel.tsx`) and D-23 (`px-7`/`py-3.5`/`py-[14px]` only in `src/components/shell/LearnerShell.tsx`) — keyed by exact file + token, proven not to leak by fixtures.
- 14 non-vacuous fixture tests: known-bad classes flagged, permitted classes pass, locked exceptions pass only at their file, parser/HTML-exclusion behavior asserted.
- Manifest groups named `primitives-table`, `primitives-forms`, `catalogue-controls-entry`, `catalogue-controls-expansion`, `catalogue-reading-entry`, `catalogue-reading-expansion`; only `primitives-table` and `primitives-forms` are made green by this plan.
- ResourceTable, ResourceForm, DetailLayout, ConfirmModal: ~90 class-string edits, all confined to type/spacing utilities. No prop, action-binding, permission, content, data or route changes.
