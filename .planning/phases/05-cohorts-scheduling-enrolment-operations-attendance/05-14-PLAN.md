<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser query string → CSV route | Filter parameters and the cohort id are caller-controlled |
| browser → enrolment Server Actions | Enrolment ids, target cohort ids and reasons are caller-controlled |
| CSV response → spreadsheet / shared cache | An export is both executable content and cacheable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-91 | Information Disclosure | The CSV export returning rows outside the caller's scope, or diverging from the on-screen filters (ATT-04) | mitigate | The route calls the same `withPermission`-gated `loadAttendanceExceptions` with the same parameters and applies no filter of its own (grep gate); bounded to the one cohort in the route param |
| T-05-92 | Information Disclosure | A scoped export served from a shared cache to a different actor | mitigate | `Cache-Control: no-store` on the CSV response |
| T-05-93 | Information Disclosure | A 403 body or filename revealing that a cohort exists | mitigate | Generic 403 body; the filename is only built after authorization succeeds |
| T-05-94 | Tampering | CSV formula injection through a learner-controlled name or correction reason | mitigate | Escaping and the `=`/`+`/`-`/`@` prefix live in `exceptionsToCsv` (plan 05-10) and are unit-tested; the route does no string assembly of its own |
| T-05-95 | Elevation of Privilege | A COHORT-scoped actor receiving a global enrolments list | mitigate | The list route relies on the factory's deny-by-default for an unscoped `list` rather than fetching everything and filtering client-side |
| T-05-96 | Repudiation | A misleading roster where a deferred column reads as a real zero (D-18) | mitigate | The `DeferredColumn`-only row type makes a number a compile error; grep gate against `?? 0`/`as unknown as number`; component test asserts no `0%` in the deferred columns |
| T-05-97 | Tampering | An enrolment transition performed without a reason or on an illegal source status | mitigate | Every action requires a 10-character reason and delegates to the service's `assertTransition`; the modal renders a failure as "action not applied" rather than an ambiguous success |
| T-05-98 | Information Disclosure | A learner-detail link from the roster exposing the learner's other, out-of-scope cohorts (D-21) | mitigate | The learner link is cohort-scoped by route and the underlying read is `cohortResourceScope`-gated; no cross-cohort aggregation is rendered here |
</threat_model>
