<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → Server Action | A Server Action is a public POST endpoint; the Origin/Host CSRF check is not authorization |
| rendered page → unauthorized viewer | Denial copy and empty states must not leak record existence or counts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-76 | Elevation of Privilege | Treating the layout guard or a hidden button as the access control | mitigate | Both actions delegate to `cohortService`/`updateCohort`, which are `withPermission`-gated on `cohorts.manage` with a DB-resolved scope; the page-level catch is presentation only |
| T-05-77 | Input Validation | Unvalidated field values reaching the service — a negative capacity, a float price, an arbitrary timezone string, a malformed date | mitigate | Strict zod schema: integer `capacity >= 1`, integer `priceMinor >= 0` (grep gate against `parseFloat`/`toFixed`), `timezone` refined through `isValidTimeZone`, dates coerced and ordered; DB CHECKs as backstops |
| T-05-78 | Tampering | Submitting both `courseId` and `programmeId`, or neither, creating an ambiguous offer (COH-01) | mitigate | zod cross-field refinement surfaced in the form summary; the `cohort_targets_exactly_one_offer` DB CHECK is the backstop |
| T-05-79 | Tampering | Changing the offer target on a cohort that already has enrolments (D-30) | mitigate | `updateCohort` calls `assertOfferMutable`; the action maps `OfferLockedError` to the specified copy rather than a 500 |
| T-05-80 | Information Disclosure | A denial that reveals whether the cohort exists, or an empty-state that leaks a count | mitigate | `AuthorizationError` collapses to one generic line; the `denied` primitive state is rendered with copy identical in both cases; component test asserts no code/count in the denied output |
| T-05-81 | Tampering | A lost update when two staff edit the same cohort | mitigate | `StaleOrderError` mapped to the specified reload copy; the service performs the conditional `updateMany` |
| T-05-82 | Information Disclosure | `@prisma/client` leaking into a route or client component, bypassing the service boundary | mitigate | grep gates on all five new files plus `tests/boundary.test.ts` in acceptance criteria |
</threat_model>
