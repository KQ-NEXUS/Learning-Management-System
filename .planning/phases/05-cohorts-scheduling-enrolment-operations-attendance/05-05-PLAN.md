## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-23 | Elevation of Privilege | A scoped Programme Manager reaching a cohort outside their grant | mitigate | `withPermission` + `toScope: cohortResourceScope` on every operation; scope read from the row, never caller-asserted; denials audited by the choke point |
| T-05-24 | Elevation of Privilege | Publishing with only `cohorts.manage` | mitigate | `publishCohort` gated on `cohorts.publish` specifically (grep gate: exactly one occurrence); unit test asserts denial for a manage-only grant |
| T-05-25 | Tampering | Changing a cohort's offer target after enrolment, silently rewriting what enrolled learners owe (COH-01) | mitigate | `assertOfferMutable` counts `Enrolment` in ANY status and throws `OfferLockedError` (D-30); tested for a `WITHDRAWN` row |
| T-05-26 | Tampering | Publishing a cohort against a draft/unpublished or unpinned catalogue record | mitigate | `NoPublishedOfferError` plus the blocking `catalogue` readiness item (D-29); the pin is set from the latest publication row inside the publish transaction |
| T-05-27 | Tampering | A concurrent edit lost by publish (last-writer-wins) | mitigate | Conditional `updateMany({ where: { id, updatedAt: expectedUpdatedAt } })` → `StaleOrderError` when `count === 0`; UI copy already specified |
| T-05-28 | Information Disclosure | An authorization refusal revealing whether a cohort exists | mitigate | `AuthorizationError` from the choke point is used unmodified; the plan-05-12/05-15 actions collapse it to one generic `DENIED` line |
| T-05-29 | Repudiation | A publish with no audit record | mitigate | `recordAudit` after commit with before/after status and reason, plus a `cohort.published` outbox row inside the transaction |
| T-05-30 | Tampering | A hard delete losing enrolment history | mitigate | No `delete` call anywhere (grep gate); `archiveData` writes `status: "CANCELLED"` |
</threat_model>
