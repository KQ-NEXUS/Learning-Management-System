<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Instructor's COHORT grant → other cohorts' learner data | Rosters carry learner identity and attendance |
| server CSV output → spreadsheet application | A CSV cell can become executable in Excel/Sheets |
| filter parameters → exported dataset | A filter applied on screen but not on export leaks rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-61 | Information Disclosure | An Instructor reading the roster of a cohort they do not teach (COH-07, D-21) | mitigate | `withPermission("cohorts.view" / "attendance.view", cohortResourceScope)`; scope from the DB row; unit test asserts `AuthorizationError` rather than an empty list |
| T-05-62 | Information Disclosure | An authorization refusal that reveals whether a cohort exists, or a roster count leaking through an "empty" response | mitigate | The choke point's `AuthorizationError` is used unmodified; the service never converts a denial into a filtered result |
| T-05-63 | Information Disclosure | CSV export leaking out-of-scope rows because the export re-queries with different filters (ATT-04) | mitigate | `exceptionsToCsv` is pure and receives the already-authorized, already-filtered rows; it issues no query; parity asserted by test |
| T-05-64 | Tampering | CSV formula injection — a learner-controlled name like `=HYPERLINK(...)` executing in a staff spreadsheet | mitigate | Values starting with `=`, `+`, `-` or `@` are prefixed with a single quote; commas/quotes/newlines are quoted and escaped; unit-tested |
| T-05-65 | Denial of Service | An unbounded export over every cohort | mitigate | `loadAttendanceExceptions` requires a cohort id and is bounded to one cohort (D-19); async export infrastructure is explicitly Phase 8 |
| T-05-66 | Repudiation | A misleading roster: a `0%` progress reading as failure or a blank reading as a bug, both hiding "no engine yet" | mitigate | `progress`/`assessment`/`completion` typed as `DeferredColumn` only, so a number is a compile error; grep gate proves no `?? 0`; attendance uses the `no-rule`/`no-sessions` third states |
| T-05-67 | Information Disclosure | A duplicated transition-history table drifting from the audit trail and being trusted instead of it | mitigate | History is read from append-only `AuditEvent`; no `EnrolmentTransition` table is created |
</threat_model>
