<objective>
Build the attendance service: single and bulk marking scoped to the cohort roster, the pre-marking
restriction, the correction-window boundary with its mandatory reason, and the `attendance.changed` event
carrying the recomputed attendance component.

Purpose: ATT-01 through ATT-03 all turn on three server-side rules that are cheap to state and easy to
skip — the learner set must come from the database not the request, the state must be legal for the
session's timing, and a post-window change must be recorded as a correction with a reason. ATT-02's
completion verdict is deliberately NOT built here: Phase 5 stores/exposes the component and emits the
event that the Phase 9/11 engine subscribes to (D-20).
Output: `attendance-service.ts`, a unit test file, and a Testcontainers integration test file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff browser → bulk attendance save | An array of learner ids and states, entirely caller-supplied |
| Instructor's COHORT grant → other cohorts' rosters | A COHORT-scoped actor must not reach a sibling cohort |
| attendance record → completion evidence | Attendance feeds ATT-02 and, later, certificates |
