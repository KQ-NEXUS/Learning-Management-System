## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deployment environment to sender identity | A missing or wrong variable could make the system send as an unapproved identity |
| user-derived strings to email html and headers | Course titles, cohort titles and references are interpolated into html and subjects |
| template params to rendered output | An event payload spread could carry a staff reason, message body or filename into a mail |
| rendered link to recipient browser | A crafted path could turn an email button into an open redirect |
